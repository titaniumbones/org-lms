description exercises the same styling features as the companion announcement,
so you can compare how Canvas renders them in an assignment body.

*Reading a photograph like this one.* Start with the waterline, then find the
debris line above it, then the vegetation edge above that. The distance between
the first two tells you about the last few days; the distance between the
second and third tells you about the last few years. Your transect should
record all three at every station.
